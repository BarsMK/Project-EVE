# Project EVE

A wearable AI-inspired engineering project built around an ESP32.

## Current Version

V0.1 — Core Interface & Scanning

## What EVE Can Do

* ESP32-based control system
* OLED interface
* Menu navigation
* Servo scanning
* Ultrasonic distance measurement
* Live angle and distance display
* Button controls
* Closest-object memory
* Remembers the angle of the closest detected object

## Hardware

* ESP32 DevKit
* SSD1306 OLED
* Ultrasonic sensor
* Servo motor
* Push buttons
* Breadboard and jumper wires

## Software

* Arduino IDE
* C/C++
* Adafruit GFX
* Adafruit SSD1306
* ESP32Servo

## Current Goals

* Finish target tracking
* Improved scanning
* More sensors
* Better hardware integration
* Wearable enclosure

## Development

Project EVE is being developed incrementally, with hardware testing and software development documented throughout the project.
